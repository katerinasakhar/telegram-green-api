# Инструкция по использованию

Приложение позволяет вести переписку текстовыми сообщениями в Telegram через
[GREEN-API](https://green-api.com/telegram/).

## Запуск приложения

```bash
npm install
npm run dev
```



## Подключение GREEN-API

1. В личном кабинете GREEN-API откройте настройки инстанса Telegram.
2. Скопируйте `idInstance` и `apiTokenInstance`.
3. В приложении откройте **Настройки GREEN-API**, вставьте оба значения и
   нажмите **Сохранить**. При первом запуске окно настроек откроется
   автоматически.

Приложение отправляет запросы на общий адрес `https://api.green-api.com`; вводить
API URL не нужно. Учётные данные сохраняются в `localStorage` этого браузера.

## Новый диалог

1. Нажмите **+** над списком чатов.
2. Выберите поиск по **Телефону** или по **Нику**.
3. Введите номер в международном формате (например, `+79991234567`) либо имя
   пользователя Telegram (например, `@username`).
4. Нажмите **Найти и открыть**. После успешной проверки аккаунта откроется чат.

Поиск по номеру может не сработать, если аккаунт не найден или настройки
приватности Telegram скрывают номер. Ник должен содержать от 5 до 32 символов.

## Переписка

- Выберите чат в списке слева, чтобы открыть переписку.
- Введите текст в поле внизу и нажмите **Отправить**. Также можно нажать `Enter`;
  `Shift+Enter` добавляет перенос строки.
- Входящие текстовые сообщения появляются в открытом приложении автоматически.
  Если сообщение пришло в другой чат, рядом с ним появится счётчик непрочитанных.
- Чтобы увидеть новые сообщения, приложение должно быть открыто и подключено.
  Статус подключения показан в заголовке чата.

Список чатов и история переписки хранятся в `localStorage` браузера и остаются
доступны при следующем запуске на том же устройстве и в том же браузере.

## Если не работает

- **Нет соединения** — проверьте интернет, значения `idInstance` и
  `apiTokenInstance`, а также состояние инстанса в личном кабинете GREEN-API.
- **Не удаётся найти собеседника** — проверьте формат номера или написание ника;
  для номера поиск также может ограничиваться настройками приватности Telegram.
- **Сообщение не отправилось** — проверьте статус подключения и настройки
  инстанса. Текст неудачной операции отображается в приложении.

Не вводите токен на общих или чужих устройствах: он сохраняется в хранилище
текущего браузера.
